## 🔐 Featured Project

### Microsoft Purview Data Governance & DLP Lab — CAPTCHA Technologies

A hands-on, simulated enterprise GRC and data-protection environment built on a live Microsoft Entra ID tenant + Microsoft 365 E5 trial — not a tutorial walkthrough. Every control is mapped to a documented risk, every test result is logged PASS/FAIL/PARTIAL, and real issues encountered are documented rather than hidden.

**What was built:**

| Area | What I implemented |
|---|---|
| 🪪 **Identity & Access** | 5 fictional department users mapped 1:1 to mail-enabled Entra ID security groups (HR, Finance, Sales, IT, Security-GRC); access granted at group level only — least privilege by design |
| 🏷️ **Data Classification** | 4-tier sensitivity label model (Public → Internal → Confidential → Highly Confidential) in Microsoft Purview, with protection scaling to risk level |
| 🛡️ **Data Loss Prevention** | Custom DLP policy combining label-based and content-based detection (AND/OR logic), deployed in simulation mode; 2 independent tests executed and passed |
| 🔎 **Audit & Investigation** | Full incident investigation (INC-001) built on a three-artifact evidence chain, plus a follow-up addendum once Unified Audit Log access stabilized |
| ⚠️ **Risk & Controls** | Risk register scoring 5 real risks (Likelihood × Impact) and a control matrix mapping 5 controls to risk, technology, and evidence |
| ✅ **Testing** | Consolidated test plan across every phase — 12 tests total: 10 PASS, 0 FAIL, 2 PARTIAL |

**Focus areas:** `Data Governance` `IAM` `Least Privilege` `RBAC` `Data Classification` `Sensitivity Labels` `DLP` `Information Protection` `Audit & Monitoring` `Risk Management` `Control Mapping` `GRC Documentation`

**Built on:** Microsoft Entra ID · Microsoft Purview (Information Protection, DLP, Audit) · Exchange Admin Center · Microsoft 365 Admin Center — **$0 cost, no Azure paid resources**
